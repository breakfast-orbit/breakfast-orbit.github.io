## よくあるご質問

### フォルダやファイルが表示されない

つづるEditは、最初にiOSの標準フォルダ選択画面で選んだフォルダを表示します。設定の「フォルダを選び直す」から、対象のフォルダをもう一度選んでください。表示対象は`.md`・`.txt`ファイルとサブフォルダです。隠しファイルや対応していない拡張子のファイルは表示されません。

### iCloud Driveのファイルが開けない、または時間がかかる

iCloud Drive上のファイルが端末にまだダウンロードされていない場合、ダウンロードが完了してから開きます。通信状態とiCloud Driveの空き容量を確認し、しばらく待ってからもう一度お試しください。

### 編集内容はいつ保存されますか

編集内容は自動保存されます。iCloud Driveのファイルを別の端末やアプリでも編集している場合、外部変更や衝突の確認が表示されることがあります。表示された場合は、残したい版を選んでください。

### Shift_JISのファイルを保存すると形式が変わると表示される

つづるEditはUTF-8、Shift_JIS、CP932（Windows-31J）のファイルを読み込めます。UTF-8以外のファイルを編集して保存すると、内容は変えずにUTF-8で保存されます。保存形式を変更したくない場合は、編集を始める前の案内で「戻る」を選んでください。

### 縦書きプレビューや原稿用紙PDFについて

`.md`ファイルはMarkdownとして解釈され、`.txt`ファイルはプレーンテキストとして表示されます。縦書きプレビューと書き出しでは、対応しているルビ記法を利用できます。原稿用紙レイアウトと原稿用紙PDFの書き出しは、買い切りのプレミアム機能です。

### プレミアム機能が反映されない、購入を復元したい

アプリの「設定」からプレミアム購入画面を開き、「購入を復元」をお試しください。購入時と同じApple Accountでサインインしている必要があります。購入状態の確認には通信が必要な場合があります。

### 返金について

App Storeでの購入に関する返金は、Appleがお取り扱いします。[reportaproblem.apple.com](https://reportaproblem.apple.com/)からお手続きください。

# <a id="en"></a>TsuzuruEdit Support (English)

<p class="lang-switch"><a href="#ja">日本語</a></p>

Thank you for using TsuzuruEdit. Please send bug reports, feature requests, and questions to the address below. TsuzuruEdit is developed and maintained by one person, so replies may take some time.

## Contact

- Email: [breakfastorbit@gmail.com](mailto:breakfastorbit@gmail.com)

## What to include

The following details help identify the problem accurately:

- Your TsuzuruEdit version and build number (shown in Settings)
- Your iOS version and device model
- What happened, and what you did just before it happened
- A screenshot, if you are comfortable sharing one

There is no need to send the file contents, the contents of your folders, or your iCloud password. If seeing part of the text is necessary to understand a problem, please first send a redacted screenshot or reproduction steps.

## Frequently asked questions

### Folders or files do not appear

TsuzuruEdit shows the folder selected through the standard iOS folder picker. Use “Choose Folder Again” in Settings to select the folder again. The App shows `.md` and `.txt` files and subfolders. Hidden files and unsupported file extensions are not shown.

### An iCloud Drive file will not open, or takes a long time

If an iCloud Drive file has not yet been downloaded to the device, TsuzuruEdit waits for the download before opening it. Check your connection and available iCloud Drive storage, wait for a moment, and try again.

### When are my edits saved?

Edits are saved automatically. If the same iCloud Drive file is edited on another device or in another app, TsuzuruEdit may show an external-change or conflict prompt. Choose the version you want to keep.

### I see a notice that the file format will change when saving a Shift_JIS file

TsuzuruEdit can read UTF-8, Shift_JIS, and CP932 (Windows-31J) files. When a non-UTF-8 file is edited and saved, it is saved as UTF-8 without changing the text. If you do not want to change the storage format, choose “Back” in the notice before starting to edit.

### Questions about vertical preview or manuscript-paper PDFs

`.md` files are interpreted as Markdown, while `.txt` files are shown as plain text. Supported ruby notation can be used in vertical preview and exports. The manuscript-paper layout and manuscript-paper PDF export are one-time premium features.

### Premium features are not available, or I want to restore a purchase

Open the premium purchase screen from Settings and choose “Restore Purchases.” You must be signed in with the same Apple Account used for the original purchase. An internet connection may be required to verify the purchase.
